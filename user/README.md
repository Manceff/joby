# `user/` — ton espace privé

Tout ce que Joby sait de toi vit ici : profil, CV, modèles LaTeX, sessions de
connexion, identifiants mail, base de données des candidatures, PDF générés.

Ce dossier est **entièrement ignoré par git** (seul ce README est versionné).
Rien de ce qui s'y trouve ne part sur GitHub.

Pour migrer vers un serveur, copie ce dossier tel quel (voir `deploy/DEPLOY.md`).
Pour tout recommencer de zéro : `joby reset`.
